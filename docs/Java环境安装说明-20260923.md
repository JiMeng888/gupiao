### 为什么选 Temurin 而不是 Oracle JDK

Temurin（Eclipse Adoptium 出品）完全免费、无商业授权限制、社区最主流，且提供 ZIP 免安装包。Oracle JDK 新版的许可协议对商业使用有限制。

## 五、安装过程记录

| 步骤 | 结果 |
|------|------|
| 版本查询 | 官方 API `api.adoptium.net` 确认最新 LTS 为 `21.0.12.1+1` |
| JDK 下载 | GitHub Releases **直连失败**（`curl: (52) Empty reply from server`），改用清华大学镜像 `mirrors.tuna.tsinghua.edu.cn/Adoptium/`，205 MB / 64 MB·s⁻¹ |
| 完整性校验 | SHA256 比对**通过**（`f9d6e191…d8b4e`，与官方 API 公布值一致） |
| Maven 下载 | `dlcdn.apache.org` 返回 404，改用 `archive.apache.org`，9.3 MB |
| 解压 | 解压至 `D:\dev-tools\`，安装包已删除 |
| 环境变量 | 用户级写入（免管理员权限） |
| 工具验证 | `java -version` / `javac -version` / `mvn.cmd -version` 三项全部正常，Maven 正确识别 JDK 21 |
| 编译验证 | `mvn -DskipTests compile` → `BUILD SUCCESS`，120 个源文件、`release 21` |
| 测试验证 | `mvn test` → **Tests run: 324, Failures: 0, Errors: 0, Skipped: 19**，`BUILD SUCCESS`（40.5s） |

### 踩到的坑（供参考）

1. **GitHub 直连被切断**：`curl` 报 `Empty reply from server`，不是网络慢而是连接被重置。国内装 JDK 建议直接用清华 / 中科大镜像。
2. **`dlcdn.apache.org` 的 Maven 目录返回 404**：改用 `archive.apache.org` 即可。
3. **PATH 分隔符**：首次写 PATH 时两条新路径之间误用了空格而非分号，导致其中一条路径失效，且连带把 `D:\vscode\Microsoft VS Code\bin`（含空格的合法路径）拆散。已修正并逐条读回校验。
4. **Git Bash 里 `mvn` 无法执行**：`bin/mvn` 是 sh 脚本，在 Git Bash 中会报 `找不到或无法加载主类 org.codehaus.plexus.classworlds.launcher.Launcher`。用 `mvn.cmd` 或在 CMD / PowerShell / IDEA 中执行均正常——**这不是安装问题**。

## 六、卸载方式

ZIP 免安装版卸载就是「删目录 + 清环境变量」：

```powershell
# 1. 删除程序目录
Remove-Item -Recurse -Force 'D:\dev-tools\jdk-21.0.12.1+1'
Remove-Item -Recurse -Force 'D:\dev-tools\apache-maven-3.9.11'

# 2. 清除用户级环境变量
[Environment]::SetEnvironmentVariable('JAVA_HOME', $null, 'User')
[Environment]::SetEnvironmentVariable('MAVEN_HOME', $null, 'User')

# 3. 从 User Path 中移除两段 bin（需手工编辑 GUI 或脚本处理）
```

本地仓库（`C:\Users\Administrator\.m2\repository`）会占几百 MB，确认不再用 Maven 时可一并删除。
