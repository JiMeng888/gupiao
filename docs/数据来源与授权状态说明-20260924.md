# 数据来源与授权状态说明

- **日期**：2026-09-24
- **用途**：如实说明本应用的数据从哪来、有没有授权、稳定性如何、代价是什么
- **性质**：合规与风险披露文档，不是技术实现文档
- **结论一句话**：**行情与资讯数据来自第三方财经网站的内部接口，未获授权；只有 AI 研判走的是官方 API。**

---

## 一、为什么要写这份文档

起因是一个很直接的问题：**「这些数据是真实的数据吗？」**

在此之前，项目里对数据来源的表述是：

| 位置 | 原文 | 问题 |
|------|------|------|
| 页脚（`DefaultLayout.vue`） | 「数据来源：行情为公开接口」 | 「公开」容易被读成「已获数据方授权」 |
| `application.yml:53` | 「东方财富公开接口（真实行情）」 | 同上 |
| README §八 | 「行情与资讯接口均为公开未鉴权接口」 | 「未鉴权」是对的，但没说明**未授权**，也没提请求头伪装 |

这三处**都不是假话，但都不够准确**——它们描述的是「不需要 key 就能调」，
而回避了「调用它是否被允许」。这次把口径改准：**能调 ≠ 获准调**。

本文档是这次口径更正的事实依据，也是后续如果要换数据源时的对照基线。

## 三、定性：不是「爬虫」，但也不是「正规接入」

### 3.1 为什么不是爬虫

**工程里零 HTML 解析能力。** `backend/pom.xml` 中没有 jsoup、htmlunit、selenium、
playwright 中的任何一个。所谓「爬虫」的典型特征是「抓 HTML 页面 → 解析 DOM 结构 →
抠出目标字段」，而本工程做的完全是另一件事：

```
抓 HTML 页面 → 解析 DOM → 抠字段     ← 爬虫（本项目没有这一步）
直接调接口 → 拿 JSON/文本 → 结构解析  ← 本项目实际做的
```

省掉了 HTML 渲染与 DOM 解析这一步，所以**术语上不属于爬虫**。

### 3.2 为什么也不是「正规接入」

调的是**各财经网站给自家网页用的内部接口**——这些接口不是对外发布的开放 API，
没有文档、没有版本契约、没有 SLA、没有配额约定。是否算「获准调用」，答案是否定的。

**所以准确的定性是：未授权接口抓取。** 与爬虫在合规风险量级上接近。

### 3.3 一个无法回避的细节：请求头伪装

`RestClientConfig.java:31-36` 把所有对外请求的请求头设置成：

| 头部 | 值 |
|------|-----|
| `User-Agent` | `Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 ... Chrome/120.0 Safari/537.36` |
| `Referer`（东财客户端） | `https://finance.eastmoney.com/` |
| `Referer`（新浪客户端） | `https://finance.sina.com.cn/` |
| `Referer`（腾讯客户端） | 不设置 |
| `Cookie` / `Authorization` / API Key | **均无** |

**即：服务端请求被装扮成「从财经频道点进来的 Chrome 浏览器」。**

代码注释里写明了这么做的原因，是**技术必要**而非刻意规避：

> 「部分财经接口会校验 Referer，缺失时返回空数据而非报错，这种『静默失败』最难排查。」

这个原因成立，但**不改变事实本身**：我们主动伪装了客户端身份。
如实披露这件事，比解释动机更重要。

> 附注：`buildClient()` 里的 `User-Agent` 是**无条件**设置的，所以连
> `llmRestClient`（DeepSeek / 百炼这些官方 API）也带浏览器 UA。对官方 API 无害，
> 但语义上不妥——调用官方 API 不该伪造浏览器身份。属可清理项，未改。

## 四、这条路的代价（已在实际运行中出现）

未授权接口的固有风险是「对方随时可改」——改字段、加风控、直接断连。
**这不只是理论风险，本项目已经在承受了。**

### 4.1 东财触发 IP 级风控，服务端主动断连

容器日志实测（`stocklab-backend`）：

```
header parser received no bytes
EOF reached while reading
```

这是**服务端在读完请求头之前就把连接关掉**的典型表现，不是我们请求写错。
触发后降级链生效：`eastmoney → tencent → mock`（冷却 30 秒）。

### 4.2 直接后果：涨幅榜会间歇性变成编造数据

因为榜单能力腾讯没有（腾讯不提供全市场涨跌榜），东财被风控时榜单**只能落到内置演示池**。

**实测采样（每 3 秒一次，共 12 次）：4 次返回演示数据，占 33%。**

演示池是固定的 10 只（`MockMarketDataProvider.STOCK_POOL`）：

| 代码 | 名称 | 基准价 | 代码 | 名称 | 基准价 |
|------|------|--------|------|------|--------|
| 600519 | 贵州茅台 | 1685.00 | 600030 | 中信证券 | 24.66 |
| 000858 | 五粮液 | 138.20 | 002594 | 比亚迪 | 246.30 |
| 300750 | 宁德时代 | 198.50 | 000001 | 平安银行 | 11.40 |
| 600036 | 招商银行 | 38.20 | 600887 | 伊利股份 | 28.90 |
| 601318 | 中国平安 | 52.85 | 688981 | 中芯国际 | 52.10 |

价格围绕基准价 ±3% 波动。

**这是最需要警惕的一点**：降级时的「涨幅榜」看起来**完全合理**——
「招商银行 +2.5%」不像乱码，它像一个正常榜单。**用户无法靠肉眼分辨。**

### 4.3 连带缺陷：搜索覆盖只有 13.5%

东财风控也影响启动预热。日志实测：

```
拉取清单第 9 页失败（已尝试 3 次）：行情上游请求失败（全A股清单 pn=9）
行情预热：第 9 页连续 3 次请求失败，停止翻页
行情预热：仅缓存 800 只（上游声明 5920 只，抓取 800 条，8 页），搜索可能无法覆盖全部标的
```

**只缓存了 800 / 5920 只（13.5%）。** 后果是这些常见标的全部搜不到：
贵州茅台 600519、五粮液 000858、宁德时代 300750、中国平安 601318、
招商银行 600036、比亚迪 002594。

根因不只是风控，还有「单页失败即整轮放弃」的策略问题——这是**独立可在本地修复的缺陷**。

### 4.4 一个容易误判的语义陷阱

`/quote/source` 的 `servingByAction` **只反映「最近一次调用」的结果，不是稳定状态**。
连续查两次就可能得到 `degraded:false` 和 `degraded:true` 两种答案。

**所以不要用单次查询判断「现在数据是真是假」。** 这也是本次核查坚持
「直连上游取真值逐个比对」而不是「看自家标记」的原因。

## 五、与上游真值的实测比对（2026-09-24）

核查方法：**绕过本应用，直连腾讯行情接口取真值**，与自家接口返回逐字段对比。

| 区块 | 结论 | 证据 |
|------|------|------|
| 大盘指数 | ✅ 真实 | 上证 3927.04 vs 腾讯 3929.51；沪深300 4494.17 vs 4498.83（差值来自两次调用时间差） |
| 精选关注 | ✅ 真实 | 兴业银行 17.93 **完全一致**；长江电力 28.15 vs 28.17；金山办公 225.60 vs 225.93（盘中跳动） |

## 八、合规方向（供评估，未实施）

要往正规走，只有两条路：

### 路线 A：换有授权的数据源

| 类型 | 选项 | 说明 |
|------|------|------|
| 免费额度 | Tushare Pro | 注册获取 token，有积分门槛与频率限制 |
| 商业终端 | 同花顺 iFinD、Wind | 需采购，有正式授权与 SLA |
| 券商接口 | 券商行情 API | 通常需开户/机构资质 |
| 授权行情商 | 交易所授权服务商 | 合规性最好，成本最高 |

**改造成本低**：`market` 包是工程里唯一允许调外部行情接口的地方，
换源只需新增一个 `MarketDataProvider` 实现，降级链会自动纳入。

### 路线 B：保留现有源，但去掉伪装

1. 移除 `User-Agent` / `Referer` 伪装（`RestClientConfig`）
2. 在页面与文档中明确标注数据来源为对应的财经网站
3. 严格控制调用频率（现有 `quote-ttl: 3s` / `bar-ttl: 5m` 缓存已经是这个方向）
4. 接受部分接口可能因此不可用（Referer 校验会静默返回空数据）

### 明确不建议的做法

- ❌ 继续把未授权接口说成「公开接口」——口径模糊不构成合规保护
- ❌ 在降级时不加标注地把演示数据当真实行情呈现
